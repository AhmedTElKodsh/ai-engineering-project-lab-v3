# Successful or reported run

Inspect the actual output and context. Identify whether it is a live provider result, a fake fixture, or a learner-reported result. A statement that it worked needs enough context to establish what worked. Do not discount a real result merely because explanation is still pending.

Describe the behavior the evidence supports, its limits and one useful next variation. Execution does not prove source truth, independent implementation or retained understanding. Do not copy a model-generated explanation into learner evidence.

When authorized, save the observation using the repository's append-only protocol and read back the resulting state. Keep missing understanding evidence pending. Never write unprovided results or progress, and never initialize the uploaded Commerce snapshot over the current workspace.
