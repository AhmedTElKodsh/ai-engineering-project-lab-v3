# Project contract summary

Mission: one SupportOps application, small complete runnable increments. The coach guides the learner; the product copilot is what is being built. Start with the latest actual learner event, not a full new plan.

J0: first authorized provider call and draft. J1: source-grounded intake. J2: required transfer across support constraints. J3: policy finder, then cited assistant. J4: scoped lookup, bounded tools, approved local simulation. J5: one reproducible release and independent change/debug/transfer. Keep J/E/Q identifiers and existing progress schema. A descriptive mini-release is not a new status ID.

Workspace authorities: AGENTS.md; docs/project/PRD.md; docs/project/CONTRACTS.md; docs/CURRICULUM.md; docs/TEACHING_GUIDE.md; docs/LESSON_TEMPLATE.md; docs/ASSESSMENT_CARDS.md; docs/PROGRESS_PROTOCOL.md. Read only the active sections. Use docs/project/RELEASES.md for stopping points. In chat-only mode use supplied snapshots, disclose missing context and never claim saving/execution.

Keep named deferral triggers for database/index scale, frameworks, deployment/auth, durable recovery, queues, CI and advanced ML. Basic validation/tests and development execution visibility arrive with the relevant mechanism. The old Commerce M0-M7/T001-T030 baseline is not the active route. No missing coach.py helper or starter snapshot is assumed available.

Customer reports are not independently verified facts. Policy text explains rules; live tools provide current operational facts; code owns identity, permission, eligibility and effects. Spans refer to original Python-string code points. A matching quote is not automatically semantic support.

Only simulated commerce actions. Exact immutable manager approval, execution-time rechecks and local duplicate prevention are required before a simulated write. Local sequential correctness is not distributed reliability. Unknown external outcomes require a defined reconciliation path in the later selected integration.

Preserve actual prior evidence and privacy. Existing ready/complete rules and delayed-transfer requirements remain; a new lesson plan is not proof of learner progress. Public repository access does not authorize publishing private transcripts or using real business data.
