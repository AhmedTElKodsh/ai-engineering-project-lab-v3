# First provider call

Resume the actual existing first-call work before setup. Explain local Python -> SDK -> authorized network request -> hosted inference -> parsed response. A model does not take control of Python. Read exact syntax from the current provider docs and verify installed project metadata.

Use one synthetic customer message and a supplied policy. The result is a draft, not an order lookup or an action. Point to messages, model selection, response and content extraction. Explain that a list-shaped response does not imply multiple choices are supported: the reviewed Groq documentation limits n to 1.

After instruction, ask one prediction and give the learner one run/change to perform. Expected output is not an observed result. A configuration error can occur before any network request; distinguish it from authentication/provider rejection. Never print keys or manufacture a paid error. A fake response supports local practice only.

Capture actual command/output and a separate learner explanation before making the corresponding evidence claims. A successful call does not complete J0 or establish retained independence. Do not add FastAPI, a queue or an embedding provider to this lesson.
