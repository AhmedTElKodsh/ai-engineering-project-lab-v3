# V3.2 — Medical and Retail Junior Application Path

**Revision date:** 2026-09-07

This is a separate revision of the supplied V3.1.4.3 guide set. It turns the earlier review and domain discussion into a project-first route for junior applied AI/LLM application roles in Egypt and eligible remote roles. The supplied Downloads folder is preserved.

The initial path is **J0 first call -> J1 medical extraction -> J2 retail triage -> J3 policy RAG -> J4 SQL/tools/state -> J5 delivery and applications**. Two evolving products produce distinct portfolio evidence. Later Q5-Q12 modules retain advanced retrieval, agents, SQL analytics, MCP, GraphRAG, open models, production/LLMOps and an independent capstone without making them all initial application gates.

Start with the [quest map](NotebookLM_Live_Source_Pack/01_AI_Engineer_Project_Quest_Map.md) and [revision notes](Maintainer_Only/V3.2_REVIEW_AND_REVISION_NOTES.md). The [portfolio guide](NotebookLM_Live_Source_Pack/05_Portfolio_Index.md) defines the evidence package and truthful resume claims.
