# Frozen teaching fixtures

Synthetic input material for the J0 and J1 increments of [the route](../docs/CURRICULUM.md).
Every file here is invented. No file contains real patient, customer or personal data,
and none may be replaced with real data.

## Why these exist

[CURRICULUM.md](../docs/CURRICULUM.md) J1 requires synthetic cases for absent facts,
negation, uncertain language, old/current statements, malformed output and
instruction-like text. [ENGINEERING_GUIDE.md](../docs/ENGINEERING_GUIDE.md) requires
local malformed-output, schema-type and source-span fixtures at J0/J1. Before this
directory existed those cases were regenerated by the tutor each session, which made
J5's rule — *"Freeze expected outcomes before running"* — impossible to satisfy: an
evaluation set that changes between sessions cannot be held out from anything.

These files are frozen. Change them only by adding new ones; edits invalidate any
measurement already taken against them.

## What is deliberately not here

**Expected outputs.** The notes and payloads are the raw material; deciding what a
correct extraction contains is the learner's work under J1, not the curriculum's.
[CASES.md](medical/CASES.md) states which behavior each fixture probes and what must
hold, without supplying a completed answer to copy.

Once the learner authors expected values, freeze them alongside the fixture and record
the model, configuration and date, per [PORTFOLIO.md](../docs/PORTFOLIO.md).

**Retail fixtures.** J2–J4 need request, policy and order material. They are not built
yet, on the curriculum's own just-in-time principle: build them when J2 is the active
increment and the schema is known, not now.

## Contents

| Path | Increment | Purpose |
|---|---|---|
| `medical/notes/` | J0 0.7, J1 | Seven synthetic notes covering the required case types |
| `medical/payloads/` | J0 0.7, J1 | Eight hand-written model-output payloads; no provider call needed |

The payloads exist so parse failure, schema failure, source-fidelity failure and span
failure can be told apart **locally, for free**. [PROVIDER_REFERENCE.md](../docs/PROVIDER_REFERENCE.md)
already says a provider request is not needed to exercise those checks; this directory
is what makes that true in practice.
